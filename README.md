# ZeroKeyUSB — Press Kit

**An offline, open-source password manager you carry on your keyring.**
ZeroKeyUSB is a USB-C device that stores your credentials and types them for you. The computer sees a standard keyboard: no cloud, no app, no account, no subscription.

🇪🇸 [Versión en español](LEEME.md)

## At a glance

| | |
|---|---|
| **What** | Hardware password manager. Shows up as a USB keyboard and types username, password and 2FA code |
| **Capacity** | 61 credentials (site, username, password up to 32 characters, optional TOTP secret) |
| **Security** | PIN entered on the device · ATECC608A secure element · AES-128 · signed firmware · resin-sealed |
| **Works with** | Windows, macOS, Linux, Android, iPadOS (USB-C). No software needed |
| **Open source** | Firmware, PCB and case files under the MIT licence: https://github.com/Depbit-lab/Zerokey |
| **Price** | $99 on Crowd Supply (shipping $8 US / $18 international) |
| **Campaign** | Launched September 22, 2026 · passed 250 % of goal · ends **November 5, 2026** |
| **Delivery** | Expected April 2027 |
| **Origin** | Began as an undergraduate thesis at the University of Cádiz (Spain), winner of the university's atrÉBT! TFG/TFM entrepreneurship award (16th edition). Developed by Depbit LLC, manufactured in Spain |
